# ASSETS

Asal-usul dan lisensi setiap aset visual dan suara (HANDOFF §10). Tidak ada aset, model, atau screenshot dari game Roblox mana pun, maupun dari Inotia 4. Inotia 4 hanya dipakai sebagai rujukan teknik, dan tidak ada piksel yang disalin darinya.

| Aset | Berkas | Asal | Lisensi |
|---|---|---|---|
| Tanah pulau (laut, pasir, rumput, dermaga) | `frontend/src/game/terrainArt.ts`, dipanggang ke `frontend/public/terrain.png` oleh `npm run bake` | dilukis per piksel oleh kode projek ini | sama dengan repo |
| Avatar, siluet ???, pelampung, tiang lentera, riak, bayangan, cahaya | `frontend/src/game/sprites.ts` | peta piksel buatan tangan di kode | sama dengan repo |
| Bangunan, kelapa, batu, semak | `frontend/src/game/props.ts` | dilukis per piksel oleh kode projek ini | sama dengan repo |
| Teri Ngantuk | `frontend/public/sprites/teri-ngantuk-40.png` | dari frame konsep generatif projek ini (18 Nov 2026): dipotong, diperkecil ke grid 40 px, dikuantisasi ke 20 warna, outline 1 px, mata dirapikan tangan | dibuat khusus untuk projek ini |
| Raja Abyss | `frontend/public/sprites/raja-abyss-{128,96,64,48}.png` | sama seperti di atas, 32 sampai 48 warna, tiap ukuran dikecilkan sendiri; mata, kumis, dan manik digambar tangan | dibuat khusus untuk projek ini |
| Font Nunito, Pixelify Sans, Silkscreen | belum di-host (ITM-05) | Google Fonts | OFL |
